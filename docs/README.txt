Resim — macOS 14 and later

Install
Drag Resim into Applications and open it there. Install updates by replacing the
app. Removing Resim does not remove original images or optimized copies.

Use
Drop PNG, JPEG, WebP, HEIC, AVIF, GIF, or SVG files from Finder into the window, or
choose Add Images… (Command-O). Processing starts automatically. By default,
each original is replaced only when the optimized result is smaller and passes
validation, keeping its name and location. Errors, cancellation, and No Reduction
leave the original unchanged.

Resim → Settings… (Command-comma) offers Automatic or Lossless optimization,
replacement of originals or copies beside them or in an output folder, and
optional removal of known personal metadata. Copy modes keep originals and add
an -optimized suffix, numbering collisions. Saved copy preferences are retained
when upgrading. Automatic
may change the image slightly. GIF remains lossless in both modes. Metadata
removal is selective; unknown metadata and information in pixels may remain.
HEIC and SVG require metadata removal to be disabled.

Escape cancels active and queued work. Completed changes remain. The context
menu can reveal files in Finder and retry errors.

Static PNG/JPEG/WebP/HEIC/AVIF, static or animated GIF, and self-contained
static SVG are supported within
the documented format and resource limits. Unsupported variants are excluded
with an explanation. Inputs are limited to 100 MB and 40 megapixels; GIF also
has frame and cumulative-pixel limits. Some smaller images may exceed the
estimated memory budget. SVG has a 4 MiB limit and excludes scripts,
animations, external resources, DTDs, and SVGZ.

The app works locally without an account, network connection, or separate
codec installation. It has no telemetry or automatic updater. Third-party
notices are available in Settings.
